# Blog

Cale blog는 개발 기록, 설계 노트, 릴리즈 소식, Lacail 진행 상황을 공개적으로 쌓는 공간이 됩니다.

## 예정된 글 흐름

- Cale이 C ABI와 공존하려는 이유
- SIR/FIR/BCIR/Sol 파이프라인 개요
- Lacail을 독립 debugger로 분리하는 이유
- GitHub Releases 기반 배포 계획

R7에서는 Astro content collection, RSS feed, JSON feed, 최신 글 카드까지 포함한 실제 blog 구조로 확장합니다.
