## 아직 binary 배포는 준비 중입니다

현재 `cale.tools`는 Cale을 설명하는 정적 문서 사이트입니다. 실제 compiler, Lacail, Qstar binary는 아직 이 사이트에서 직접 제공하지 않습니다.

## 예정된 배포 방식

향후 배포는 GitHub Releases 기반으로 진행할 예정입니다.

- release note
- platform별 binary artifact
- checksum
- source archive
- 빠른 시작 문서

## 현재는 source 중심

지금은 Cale repository의 source build와 각 하위 프로젝트의 Makefile 기반 check가 가장 정확한 사용 경로입니다.
