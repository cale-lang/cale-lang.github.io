# Install

Cale은 아직 일반 사용자를 위한 바이너리 배포 단계가 아닙니다. 지금은 source build 중심으로 프로젝트를 확인하고, 이후 GitHub Releases 기반 배포가 준비되면 이 페이지가 공식 설치 진입점이 됩니다.

## 현재 상태

- **Source build**: Cale 저장소에서 직접 빌드하는 개발자 경로
- **Binary release**: GitHub Releases 기반으로 준비 예정
- **Lacail**: 독립 debugger 프로젝트로 `lacail/Makefile` 중심 빌드 경계를 유지
- **Qstar**: Cale 본체와 분리된 주변 도구 프로젝트

## 다음 라운드에서 채울 정보

R5에서는 macOS, Linux, Windows 상태 표와 source build 명령, release artifact 정책, editor/tooling 안내를 정리합니다.
