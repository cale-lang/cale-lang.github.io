# Install

Cale is not yet distributed as end-user binary releases. For now, this page is the install entry point for source builds and the future home for GitHub Releases based binaries.

## Current status

- **Source build**: developer-oriented build from the Cale repository
- **Binary release**: planned through GitHub Releases
- **Lacail**: standalone debugger project with a `lacail/Makefile` boundary
- **Qstar**: adjacent tooling kept separate from Cale core

## Next

R5 will add platform status, source build commands, release artifact policy, and editor/tooling notes.
